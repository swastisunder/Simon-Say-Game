# Simon Says Game

Simon Says is a classic memory and reflexes testing game implemented in JavaScript. Test your memory and concentration by following the sequence of button flashes. How far can you go?

## How to Play

- Press any key to start the game.
- Simon will show a sequence of button flashes.
- Repeat the sequence by clicking on the buttons.
- Each successful round increases your level.
- The game ends if you make a mistake.
- Your score is displayed as the highest level reached.

## Technologies Used

- HTML
- CSS
- JavaScript
